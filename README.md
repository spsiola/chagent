# chagent

Асинхронный ИИ-агент (AI Agent) на Python, с поддержкой Model Context Protocol (MCP) и мульти-провайдерной архитектурой (поддержка локальных моделей через Ollama и fallback на OpenAI).

## Основные возможности

- **Асинхронность**: Построен на базе `asyncio` и асинхронного клиента `openai` для высокой производительности.
- **Поддержка MCP (Model Context Protocol)**: Позволяет динамически подключать внешние серверы с инструментами (tools) (например, через `stdio` и `npx`) и автоматически регистрировать их для использования агентом.
- **Отказоустойчивый выбор LLM**: Автоматически тестирует доступные LLM-провайдеры (например, локальный Ollama, затем OpenAI) и выбирает первый работающий.
- **Поддержка вызовов функций (Tool Calling)**: Встроенная обработка `tool_calls` от LLM, включая fallback-режим для моделей, которые возвращают инструменты в виде JSON-строки.

## Требования

- Python 3.13+
- Зависимости (управляются `uv`, см. `pyproject.toml`):
  - `openai`, `mcp`, `pydantic`, `pydantic-settings`, `pyyaml`, `httpx`
- Node.js (для запуска тестовых MCP серверов через `npx`)

## Установка и запуск

1. Склонируйте репозиторий.
2. Установите зависимости (рекомендуется использовать `uv`):
   ```bash
   uv venv
   source .venv/bin/activate
   uv pip install -e .
   ```
3. Убедитесь, что у вас настроен конфигурационный файл `config.yaml` в корне проекта (по умолчанию используются локальный Ollama и запасной вариант OpenAI).
4. Запустите агента:
   ```bash
   chagent
   ```
   Или через Python:
   ```bash
   python -m chagent.main
   ```

## Конфигурация

Проект использует `config.yaml` для настройки провайдеров. Пример:
```yaml
providers:
  - name: "ollama_local"
    type: "openai_compatible"
    base_url: "http://localhost:11434/v1"
    api_key: "ollama"
    models:
      - "qwen2.5-coder:7b"
      - "llama3.1:8b"
```

## Разработка

Для добавления новых инструментов напрямую в агента можно использовать метод `register_tool()` объекта `AsyncAgent`. Для добавления внешних возможностей используйте MCP-серверы через `MCPManager`.

Подробнее об архитектуре читайте в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
