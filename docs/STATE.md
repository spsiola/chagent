# Текущее состояние проекта (STATE)

**Версия:** 0.8.0
## Реализованные функции
- **Отслеживание токенов и статистика:** Встроенная оценка токенов, отображение бейджа в UI. Добавлен `StatsManager` (SQLite) для детального сбора метрик (задержка, токены, кэш) и вкладка в UI для просмотра статистики. Агенту доступен инструмент `query_llm_stats`.
- **Восстановление сессии:** При перезагрузке страницы или новом подключении по WebSocket клиенту отправляется история системных логов и полная история диалога в правильном хронологическом порядке.
- **Новая личность агента:** Настроена дефолтная личность агента (Капитан Зелёный).
- Улучшена верстка веб-интерфейса: двухстрочный хедер, просторное модальное окно настроек (90% ширины окна) с вертикальными табами. Добавлены сворачиваемые блоки (аккордеоны) для скрытия длинных JSON-аргументов и результатов вызова инструментов.
- Поднят веб-сервер на FastAPI (`serve` mode).
- Интеграция с локальными LLM через Ollama (протестировано с `qwen2.5-coder:7b`).
- Поддержка протокола Model Context Protocol (MCP) с использованием `npx @modelcontextprotocol/server-everything`.
- Потоковая генерация ответов через WebSockets (SSE-like events over WS).
- **Память агента**: Агент запоминает контекст диалога.
- **Robust Tool Parsing**: Реализован фоллбэк-парсер, который умеет выцеплять вызовы функций (JSON) из текста модели, скрывая их от пользователя и правильно инжектируя в системный контекст. Агент также перехватывает `JSONDecodeError` для защиты от "сломанных" ответов LLM.
- Кнопка "Скопировать диалог" в UI для отладки. Копируемый текст содержит информацию о провайдере и модели.
- Безопасное завершение (graceful shutdown) по `Ctrl+C` (перехват `KeyboardInterrupt`).
- **Динамическое переключение моделей**: Выбор модели и провайдера прямо в UI с тестированием "на лету" без перезапуска сервера.
- **Шаблонизация памяти**: Контекст собирается динамически через `MemoryManager`, шаблоны и правила инструментов настраиваются через веб-интерфейс (без хардкода в Python).
- **Вкладка Инструменты**: Позволяет через UI в реальном времени просматривать массив `agent.tools`, передаваемый модели.
- **Инициализация "С нуля" (init_memory)**: При старте сервера без данных (отсутствие папки `data`), агент автоматически копирует базовую "личность" (скиллы, mcp конфиг, дефолтные шаблоны) из папки `init_memory`.
- Встроен мощный скилл `skill-creator` для написания и отладки собственных скиллов через чат.
- **Нативные инструменты (`native_tools.py`)**: Агент может напрямую читать/писать файлы, просматривать директории и выполнять команды в консоли без использования MCP, что в разы ускоряет работу.
- **Песочница и безопасность (Sandboxing)**: Нативные инструменты защищены механизмом `safe_mode`. Предотвращается выход за пределы разрешенных директорий (Path Traversal), выполнение произвольных shell-команд, а также блокируется модификация собственных `.py` файлов для защиты от самомодификации ИИ-агентом.
- **Фоновая загрузка и логирование Harness**: Сервер запускается мгновенно, а процесс загрузки агента логируется в терминал и UI в реальном времени.
## Известные проблемы / Ограничения
- Локальные LLM (например, Qwen) иногда могут "зацикливаться" на вызове инструментов, если промпт или системные сообщения не достаточно ясны.
- MCP сервер запускается через дочерний `npx` процесс. При жесткой остановке он может бросать `EPIPE`, но это обрабатывается (игнорируется).

## Как запускать
```bash
uv run chagent serve
```
