# Текущее состояние проекта (STATE)

**Версия:** 0.1 (локальный тег)

## Реализованные функции
- Поднят веб-сервер на FastAPI (`serve` mode).
- Интеграция с локальными LLM через Ollama (протестировано с `qwen2.5-coder:7b`).
- Поддержка протокола Model Context Protocol (MCP) с использованием `npx @modelcontextprotocol/server-everything`.
- Потоковая генерация ответов через WebSockets (SSE-like events over WS).
- **Память агента**: Агент запоминает контекст диалога.
- **Robust Tool Parsing**: Реализован фоллбэк-парсер, который умеет выцеплять вызовы функций (JSON) из текста модели, скрывая их от пользователя и правильно инжектируя в системный контекст.
- Кнопка "Скопировать диалог" в UI для отладки.
- Безопасное завершение (graceful shutdown) по `Ctrl+C` (перехват `KeyboardInterrupt`).

## Известные проблемы / Ограничения
- Локальные LLM (например, Qwen) иногда могут "зацикливаться" на вызове инструментов, если промпт или системные сообщения не достаточно ясны.
- MCP сервер запускается через дочерний `npx` процесс. При жесткой остановке он может бросать `EPIPE`, но это обрабатывается (игнорируется).

## Как запускать
```bash
uv run chagent serve
```
