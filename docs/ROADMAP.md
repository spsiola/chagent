# План развития проекта (ROADMAP)

## Краткосрочные задачи
- [x] Подключить реальные, полезные инструменты (поиск в интернете, работа с локальными файлами). (Реализовано через `native_tools.py` и `mcp`)
- [x] Разработать базовую систему безопасности (Sandboxing/Permissions) для нативных инструментов (запрет удаления системных папок, ограничение запуска опасных скриптов, Human-in-the-Loop для важных команд).
- [x] На уровне Harness сделать отслеживание размеров сообщений для ЛЛМ (всего диалога) в токенах (или символах, примерно) и показывать это в UI.
- [x] На уровне Harness сделать отслеживание статистики работы с конктеретными LLM - отправленных токенов, полученных, попаданий в кэш, скорости ответа. Собирать статистику за каждую сессию. Хранить в локальной базе данных sqlite в отдельной папке, использовать скилл для доступа к этой базе данных через MCP. Интерфейс к статистике в Harness. 
- [x] Настроить правильный системный промпт (system prompt) для ИИ-агента, чтобы задать ему личность и формат общения.
- сделать аналог cron job для запуска скиллов по расписанию. 
- Реализовать настоящий стриминг ответов (Streaming) от LLM через WebSocket для плавного вывода текста.
- Добавить сворачиваемые блоки ("аккордеоны") для скрытия вызовов инструментов и их JSON-аргументов в чате.

## Среднесрочные задачи
- Подключение агенту возможность вызывать Antygravity CLI с конкретными задачами, через стандартный A2A https://github.com/a2aproject
- Рефакторинг `agent.py` для поддержки многопользовательского режима (сессии на каждого подключенного пользователя по WebSocket с виртуальными "личностями" - разными системными промптами для ИИ-агента).
- Завершение настройки репозитория (добавление `gh repo create` / отправка на GitHub).
- Поддержка полноценного Markdown-рендеринга (marked.js) и подсветки синтаксиса (Prism.js/Highlight.js) в интерфейсе чата.

## Долгосрочные задачи
- Мульти-агентная архитектура.
- Интеграция с локальной векторной базой знаний.
