# План развития проекта (ROADMAP)

## Краткосрочные задачи
- [x] Подключить реальные, полезные инструменты (поиск в интернете, работа с локальными файлами). (Реализовано через `native_tools.py` и `mcp`)
- [ ] Разработать базовую систему безопасности (Sandboxing/Permissions) для нативных инструментов (запрет удаления системных папок, ограничение запуска опасных скриптов, Human-in-the-Loop для важных команд).
- На уровне Harness сделать отслеживание размеров сообщений для ЛЛМ (всего диалога) в токенах (или символах, примерно) и показывать это в UI.
- На уровне Harness сделать отслеживание статистики работы с конктеретными LLM - отправленных токенов, полученных, попаданий в кэш, скорости ответа. Собирать статистику за каждую сессию. Хранить в локальной базе данных sqlite в отдельной папке, использовать скилл для доступа к этой базе данных через MCP. Интерфейс к статистике в Harness. 
- Настроить правильный системный промпт (system prompt) для ИИ-агента, чтобы задать ему личность и формат общения.
- сделать аналог cron job для запуска скиллов по расписанию. 

## Среднесрочные задачи
- Подключение агенту возможность вызывать Antygravity CLI с конкретными задачами, через стандартный A2A https://github.com/a2aproject
- Рефакторинг `agent.py` для поддержки многопользовательского режима (сессии на каждого подключенного пользователя по WebSocket с виртуальными "личностями" - разными системными промптами для ИИ-агента).
- Завершение настройки репозитория (добавление `gh repo create` / отправка на GitHub).
- Поддержка Markdown-форматирования (например, таблиц) и подсветки синтаксиса (highlight.js) в интерфейсе чата.
