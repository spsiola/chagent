# История изменений (Changelog)

Все заметные изменения проекта фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), а проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-09
### Добавлено
- Базовая структура проекта с инициализацией через `uv`.
- `AsyncAgent` - потоковый агент, умеющий вызывать Python-функции как инструменты.
- Подключение к локальной Ollama (авто-выбор Qwen 2.5).
- Интеграция с Model Context Protocol (`mcp_integration.py`).
- FastAPI сервер (`server.py`) с поддержкой WebSockets для передачи событий клиенту в реальном времени.
- Красивый UI с эффектом Glassmorphism (HTML/CSS/JS в `src/chagent/static`).
- "Фоллбэк-парсер" в агенте для разбора сырых JSON-блоков из текстового потока, что решает проблему вызова инструментов у некоторых локальных моделей.
- Кнопка "Скопировать диалог" для отладки чата.
- Удержание истории диалога в памяти агента (`self.history`).
- Глобальная обработка `KeyboardInterrupt` для чистого выхода при `Ctrl+C`.
- Документация в папке `docs/` (`ARCHITECTURE.md`, `STATE.md`, `ROADMAP.md`, `CHANGELOG.md`) и стартовый файл для ИИ `AGENTS.md`.
