# История изменений (Changelog)

Все заметные изменения проекта фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), а проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.6.0] - 2026-09-10
### Добавлено
- **Отслеживание токенов**: На уровне Harness добавлена оценка размеров сообщений для ЛЛМ (приблизительное число токенов с учетом кириллицы). Данные отправляются через новое событие `metrics` в WebSocket.
- **Новый интерфейс**: Полностью переработана верхняя панель (header) для лучшего использования пространства (двухстрочная компоновка).
- В UI под полем ввода сообщений добавлен компактный индикатор текущего количества токенов в контексте.
- **Дефолтная личность**: Настроен правильный системный промпт для ИИ-агента — прагматичный и ворчливый Капитан Зелёный.

## [0.5.0] - 2026-09-10
### Добавлено
- **Песочница и безопасность (Sandboxing)**: Добавлена архитектура безопасности лучших практик MCP в нативные инструменты (`native_tools.py`).
- Настройка `safe_mode` (по умолчанию `True`), которая ограничивает права агента на файловую систему и ОС.
- В `safe_mode` все пути жестко привязываются к разрешенным директориям (корням), предотвращая Path Traversal.
- В `safe_mode` запуск произвольных shell-команд через `run_command` полностью отключен.
- Защита от самомодификации: даже внутри разрешенных директорий агент в `safe_mode` не может перезаписывать или создавать файлы с расширением `.py`, защищая логику самого приложения от случайных или намеренных изменений агентом.
- Настройки `safe_mode` и `allowed_roots` добавлены в `src/chagent/settings.py` и прокидываются в `native_tools.py` через `register_native_tools`.

## [0.4.0] - 2026-09-10
### Добавлено
- Внедрены нативные инструменты (`native_tools.py`): `read_file`, `write_file`, `list_directory`, `run_command` для прямой работы с файловой системой и ОС, минуя MCP.
- Добавлена новая вкладка "Инструменты" в модальном окне настроек для просмотра актуального списка `agent.tools`, которые отсылаются LLM.
- Добавлен эндпоинт `/api/tools` для получения списка инструментов.

### Изменено
- Улучшена обработка ошибок LLM: в `agent.py` добавлен безопасный парсинг `tool_calls` для перехвата `JSONDecodeError`, чтобы предотвратить ошибки HTTP 400 из-за некорректных ответов.
- Обновлен UI: добавлен вертикальный скролл (`overflow-y: auto`) для содержимого модального окна настроек.
- Обновлен UI: отключено кеширование вкладки "Справка", теперь файл актуализируется при каждом открытии вкладки.
- Обновлен UI: добавлена обертка строк (`word-wrap`) для блоков кода в Markdown, чтобы убрать горизонтальный скроллинг.

## [0.3.0] - 2026-09-10
### Изменено
- Архитектура вынесения контекста в `MemoryManager`. Системные промпты, шаблоны и правила инструментов вынесены из захардкоженного кода в редактируемые поля (доступные через UI).
- Механизм `init_memory`: при первом запуске (если рабочая директория `data` пуста), агент инициализирует свою "личность" и настройки, копируя их из папки `init_memory`.
- В UI добавлена новая вкладка "Структура контекста", позволяющая на лету редактировать шаблон системы и правила для инструментов.
- Улучшена обработка ошибок LLM — теперь они логируются в UI как "Harness" логи, а UI-элементы корректно блокируются/разблокируются при потере соединения.

### Добавлено
- Скилл `skill-creator` от Anthropic добавлен в базовую сборку (`init_memory/skills`) для помощи в создании новых скиллов прямо из агента.

## [0.2.0] - 2026-09-10
### Изменено
- Веб-сервер теперь стартует мгновенно, а инициализация агента и MCP происходит в фоновом режиме.
- Добавлена трансляция системных сообщений (Harness logs) в веб-интерфейс в реальном времени.
- В UI добавлен чекбокс для скрытия/отображения системных логов.
- Очередь сообщений с настраиваемым таймаутом (`startup_timeout`) для пользователей, которые пишут в чат до завершения инициализации.
- Добавлен выпадающий список для динамического переключения провайдеров и моделей через UI.
- Новые API-эндпоинты `/api/models` и `/api/models/switch` для управления состоянием агента на лету.

## [0.1.0] - 2026-09-09
### Добавлено
- Базовая структура проекта с инициализацией через `uv`.
- `AsyncAgent` - потоковый агент, умеющий вызывать Python-функции как инструменты.
- Подключение к локальной Ollama (авто-выбор Qwen 2.5).
- Интеграция с Model Context Protocol (`mcp_integration.py`).
- FastAPI сервер (`server.py`) с поддержкой WebSockets для передачи событий клиенту в реальном времени.
- Красивый UI с эффектом Glassmorphism (HTML/CSS/JS в `src/chagent/static`).
- "Фоллбэк-парсер" в агенте для разбора сырых JSON-блоков из текстового потока, что решает проблему вызова инструментов у некоторых локальных моделей.
- Кнопка "Скопировать диалог" для отладки чата.
- Удержание истории диалога в памяти агента (`self.history`).
- Глобальная обработка `KeyboardInterrupt` для чистого выхода при `Ctrl+C`.
- Документация в папке `docs/` (`ARCHITECTURE.md`, `STATE.md`, `ROADMAP.md`, `CHANGELOG.md`) и стартовый файл для ИИ `AGENTS.md`.
