# Как Chagent общается с LLM

Архитектура Chagent спроектирована так, чтобы абстрагировать от LLM-модели разницу между MCP-серверами и нашими локальными Python-скиллами. Для модели все они выглядят одинаково — как стандартный вызов функции (Tool Calling).

## Структура контекста (`history`)

Каждый раз, когда вы отправляете сообщение, агент формирует массив `history`, который отправляется к LLM. Вот из чего он состоит:

### 1. Системный промпт (history[0])
Самый первый элемент массива всегда имеет роль `system`.
Он формируется динамически подсистемой `MemoryManager` и склеивается из:
- Основной роли и инструкций (настраивается во вкладке "Промпты")
- Списка всех доступных на данный момент инструментов (Python-скиллы и MCP-инструменты).
- Правил использования инструментов.

*Примечание: Инструменты также передаются модели через специальный нативный параметр API `tools`. Дублирование их в тексте `history[0]` помогает менее сообразительным локальным моделям лучше понимать свои возможности.*

### 2. История переписки
Далее идут сообщения от вас (`role: user`) и ответы от модели (`role: assistant`).

### 3. Вызовы инструментов (Tool Calls)
Если модель решает, что для ответа нужно использовать инструмент (прочитать файл, запустить скрипт, загрузить скилл), она возвращает не текст, а **запрос на вызов инструмента**.
Этот запрос попадает в историю как:
```json
{
  "role": "assistant",
  "tool_calls": [
    {
      "id": "call_123",
      "type": "function",
      "function": { "name": "имя_инструмента", "arguments": "{...}" }
    }
  ]
}
```

### 4. Ответы инструментов (Tool Results)
Система (Harness) перехватывает этот вызов, исполняет соответствующий код (или делает запрос к MCP), дожидается результата и вкладывает его в историю как ответ инструмента:
```json
{
  "role": "tool",
  "tool_call_id": "call_123",
  "name": "имя_инструмента",
  "content": "Результат выполнения: успех."
}
```

После этого Harness **автоматически делает еще один запрос к LLM**, передавая обновленную историю. Модель читает результат и формирует уже текстовый ответ для вас.

---
*Этот документ будет пополняться по мере того, как сам Harness (система оркестрации) будет брать на себя более активное участие в формировании истории и управлении контекстом.*
