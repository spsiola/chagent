# Инструкция по обновлению HOW_IT_WORKS.md

Твоя задача — проанализировать исходный код агента и переписать файл справки.
⚠️ КРИТИЧЕСКИ ВАЖНО: ТЫ ОБЯЗАН ИСПОЛЬЗОВАТЬ ИНСТРУМЕНТЫ `read_file` И `write_file`. НИЧЕГО НЕ ПИШИ ПО ПАМЯТИ! ⚠️

Выполни строго следующие шаги один за другим:

1. **Шаг 1:** Вызови инструмент `read_file` с аргументом `path: "src/chagent/agent.py"`. Дождись ответа системы с содержимым файла. Проанализируй логику формирования массива истории (`history`).
2. **Шаг 2:** Вызови инструмент `read_file` с аргументом `path: "src/chagent/memory_manager.py"`. Дождись ответа. Изучи, как собирается системный промпт.
3. **Шаг 3:** Подготовь новый подробный текст для справки `data/HOW_IT_WORKS.md`. 
   Текст должен быть объемным (не менее 400 слов) и содержать глубокий технический анализ прочитанного кода. 
   Обязательно включи в текст:
   - Примеры JSON-объектов из массива `history` (как выглядит системный промпт, как выглядят `tool_calls` от ассистента, как выглядят ответы инструмента `tool_result`).
   - Объясни механику из `memory_manager.py`: как `build_system_prompt` подставляет список инструментов в текстовый шаблон.
   - Объясни механику из `agent.py`: как добавляются сообщения, как работает фолбэк (`is_fallback`) для локальных моделей (ручной парсинг JSON из текста), и как перехватываются ошибки `JSONDecodeError` с подменой битых аргументов на `"{}"`.
   Пиши структурированно, с заголовками и блоками кода. Сохрани смысловую структуру: 1. Системный промпт, 2. История, 3. Вызовы инструментов, 4. Ответы. Пиши на русском языке.
4. **Шаг 4:** Вызови инструмент `write_file` с аргументами `path: "data/HOW_IT_WORKS.md"` и `content: "твой_новый_текст"`. 
5. **Шаг 5:** Сообщи пользователю об успешном завершении задачи.
